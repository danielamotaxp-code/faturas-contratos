Leitura de planilhas pelo link do Google

Para gerar a partir do link, a plataforma usa uma chave de API do Google (feita uma vez, gratuita). Situação:

Como criar a chave (uma vez só)
  1. Abra console.cloud.google.com/projectcreate, dê o nome WattWise Plataforma e clique em Criar.
  2. Abra a página da Google Sheets API, confira se o projeto WattWise Plataforma está selecionado no topo e clique em Ativar.
  3. Abra Credenciais → Criar credenciais → Chave de API. Copie a chave que aparecer.
  4. Clique em Editar chave de API (ou no nome da chave). Em Restrições de aplicativos, escolha Sites e adicione https://danielamotaxp-code.github.io/*. Em Restrições de API, escolha Restringir chave e marque Google Sheets API. Clique em Salvar.
  5. Cole a chave acima e clique em Salvar chave.
